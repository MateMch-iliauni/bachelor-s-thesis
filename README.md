# გაზქურის მონიტორინგის სისტემა

ეს არის "გაზქურის მონიტორინგის სისტემა"-ის ოფიციალური რეპოზიტორია,  საბაკალავრო ნაშრომი 2025-2026. სისტემა შექმნილია გაზქურის უსაფრთხოების მონიტორინგისა და დისტანციური შეტყობინებების მართვისთვის.

## პროექტის სტრუქტურა

რეპოზიტორია ორგანიზებულია შემდეგი საქაღალდეების მიხედვით:

- `Project-Codes/`: შეიცავს ESP32-S-ზე გაშვებულ firmware-ს, მათ შორის თერმული კამერის ღილაკის და ბაზერის მართვისა და Telegram bot-ის ლოგიკას.
- `project-diagrams/`: სისტემის არქიტექტურის დიაგრამები.
- `Production_drawings/`: პროექტის ტექნიკური ნახაზები და CAD ფაილები.
- `documentation/`: დოკუმენტაცია, მომხმარებლის სახელმძღვანელო.
- `Final-Presentation/`: საბოლოო პრეზენტაცია.
- `Attachments/`: დამატებითი ტექნიკური მასალები და კვლევითი ფაილები.

## სისტემის მახასიათებლები
- **აპარატურა:** ESP32-S მიკროკონტროლერი, 3-პინიანი KY-012 აქტიური ბაზერი თერმული კამერა და ღილაკი.
- **პროგრამული ლოგიკა:** თერმული კამერა, ბაზერი და Telegram bot-ის ლოგიკა გადანაწილებულია მრავალბირთვიან პროცესორზე.
- **ინტერფეისი:** დისტანციური შეტყობინებების მიღება Telegram Bot API-ს მეშვეობით.
